# A High-Value Investment Guidebook

> Get the most long-term real return, lower volatility, tax and fee savings, and avoidance of total loss — at the cost of the least fees, taxes, time, effort, and permanent loss of principal.

## How to Read This

- **You don't have to do it all**: This is a cost-ranked menu of options, not a to-do list. Take one or two items and it counts; leave the rest and come back when you need them.
- **The Three-Zeros principle (the highest-value hard standard)**: An action counts as "Three Zeros" if **cost = none, time = none, willpower = none** — all three costs are zero. Exactly 16 entries meet this strictly (e.g., "don't touch illiquid alternative assets you don't understand," "reinvest dividends," "keep emergency cash in a money-market fund," "sweep up idle cash with reverse repos," "open a personal pension account for the tax break," "use the 4% rule to estimate your retirement gap"), so do them first without overthinking. Many more actions fall in the high-value tier of "two zeros and one very low cost" — on the search page you can filter by "cost / time / willpower" set to "none" to dig them out.
- **Want to filter by criteria**: Open the [online search page](https://leo-bone.github.io/HowToInvestBetter/), filter by keyword, chapter, or evidence level, and also by the three dimensions of "does it cost money / how much time / does it take willpower," which can be stacked together. The page content is drawn directly from the `book/` source files, so it updates the moment the content changes.
- **Entries cross-reference each other** ("see entry 17 in Chapter 8," etc.): On the search page, a reference shows as a dashed line; click it to reveal the referenced entry's title and plain-language summary right there.
- **Want to read in order**: Within each chapter, entries are ranked from highest to lowest value, so just start with the first few.
- **Want to read offline or share it**: Download the [offline single-file HTML](https://leo-bone.github.io/HowToInvestBetter/offline.html); the whole book — including search and filtering — lives in that one file. Double-click to open; no server or internet needed, and it sends fine over WeChat too.
- **Want to print or read on your phone**: Download the [PDF](https://github.com/leo-bone/HowToInvestBetter/raw/main/HowToInvestBetter.pdf) — A4 layout, 200+ pages, with a table of contents, page numbers, and bookmarks; each section starts on a new page.
- **Want to read on a Kindle or other e-reader**: Download the [EPUB ebook](https://github.com/leo-bone/HowToInvestBetter/raw/main/HowToInvestBetter.epub); it opens in Apple Books, WeChat Reading, calibre, or Kindle.
- **All three are auto-regenerated after every content update**; the download links stay fixed. The copy you forward won't follow updates — trust the online version.
- **Don't be put off by chapter titles starting with "Don't"**: The title names what that chapter helps you avoid; the actual actions to take are in the entry titles (which start with a verb).
- **Can't read the numbers?**: Every entry has a "plain-language" line that rewrites the research jargon of the "return" column into everyday language — that one line is enough to make your decision.
- **Honest labeling**: Where a conclusion has limits or a contrary view, we mark it `〔争议〕`; every entry states its evidence level (A / B / C).

## Build Your Own Copy

Most people don't need to deploy anything: just use the `offline.html` in the repo, or open the [online search page](https://leo-bone.github.io/HowToInvestBetter/).

```
git clone https://github.com/leo-bone/HowToInvestBetter.git
cd HowToInvestBetter
python3 -m http.server 8000
```

Open `http://localhost:8000/` in your browser. The search page is purely static; `book/` and `data.js` are its data — no backend, no database, no dependencies to install.

**Regenerate the data** (after editing `book/`):

```
python3 tools/build.py
```

This regenerates `data.js` and the inline-data `offline.html`, and runs a field-completeness check on every entry. The script depends only on the Python standard library.

**Generate the EPUB ebook** (after editing `book/`, if you want a nicely laid-out ebook):

```
python3 tools/build_epub.py
```

Parses `book/` to produce `HowToInvestBetter.epub` (cover + chapters + table of contents + styles). Also pure standard library, no dependencies to install.

**Generate the PDF ebook** (for a print-style / physical-book feel):

```
pip install reportlab
python3 tools/build_pdf.py
```

Uses the system's built-in CJK font to generate `HowToInvestBetter.pdf` (cover + introduction + table of contents + chapters + footer page numbers). `reportlab` is installed only at build time; readers opening the PDF need no dependencies.

**Generate a share cover image**:

```
python3 tools/gen_cover.py
```

Generates `cover.png` (1200×630) for social-share cards and the ebook cover. Requires `Pillow`.

**One-click push to GitHub** (when the system `git` is unavailable):

```
python3 tools/sync.py
```

Commits and pushes the `main` branch using credentials already stored in the repo.

**Content quality check** (pre-commit / for CI):

```
python3 tools/lint.py
```

Checks: field completeness, no leftover "to be verified" markers, unique IDs, evidence distribution, and valid cross-references. A non-zero return means there's a problem.

## How Evidence Is Graded

- [A] Authoritative long-term statistics (S&P SPIVA, exchange yearbooks), randomized/longitudinal studies in top journals, official regulatory documents.
- [B] Individual high-quality studies, backtest reports from authoritative institutions (Vanguard / Dalbar / Ibbotson), classic papers.
- [C] Reasonable inference / broad consensus — logically sound but not force-fit to a precise citation.

Current distribution: 136 entries at Level A, 105 at Level B, 58 at Level C.

> **Verification status**: In this version every figure has been checked against official documents or authoritative research; the text contains no unverified `〔待核实〕` entries. Where a conclusion has limits or a contrary view, it is still marked `〔争议〕`.
