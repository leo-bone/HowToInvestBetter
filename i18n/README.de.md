# Ratgeber für kostengünstiges Investieren

> Mit möglichst wenig Gebühren, Steuern, Zeit, Aufwand und dauerhaftem Kapitalverlust die höchste langfristige Realrendite, geringere Schwankungen, Steuerersparnisse und die Vermeidung des Totalverlusts erzielen.

Ein **evidenzbasiertes Investment-Handbuch**, 24 Kapitel, 302 Einträge. Jeder Hinweis gibt an:

- **Was es kostet** (Gebühren / Steuern / Zeit / Aufwand / dauerhafter Kapitalverlust)
- **Was es bringt** (langfristige Realrendite p.a. / geringere Schwankungen / Steuerersparnis / Vermeidung von Totalverlust)
- **Wie belastbar die Belege sind** 〔A Behördenstatistik · Top-Journale · offizielle Dokumente ｜ B Einzelstudie · Institutsbericht ｜ C plausible Schlussfolgerung · Gesetz〕
- **Ursprungsquelle**: Es werden nur Fachartikel und offizielle Dokumente zitiert, keine Social-Media- oder Marketingkanäle.

## So lesen Sie es

- **Nicht alles umsetzen**: Dies ist eine nach Kosten-Nutzen geordnete Auswahlliste, keine Aufgabenliste. Schon ein oder zwei Punkte zählen; den Rest lassen Sie liegen und schlagen bei Bedarf nach.
- **Drei-Null-Prinzip (sehr hoher Kosten-Nutzen, harte Regel)**: Ein Hinweis gilt als „Drei-Null“, wenn Kosten = null, Zeit = null und Willenskraft = null, also alle drei Aufwände bei null liegen. Genau 16 Hinweise erfüllen das strikt (z. B. „nur nicht-standardisierte Produkte meiden, die man nicht versteht“, „Dividenden reinvestieren“, „Geldmarktfonds für die Notreserve“, „Repos als Kleinkram mitnehmen“, „Altersvorsorgekonto für Steuervorteile eröffnen“, „4 %-Regel für die Versorgungslücke“). Machen Sie die am besten sofort. Viele weitere Hinweise liegen in der „zwei Nullen, ein sehr niedriger Wert“-Kategorie mit hohem Nutzen – auf der Suchseite lässt sich nach „Kosten / Zeit / Willenskraft“ jeweils auf „null“ filtern.
- **Nach Kriterien filtern**: Öffnen Sie die [Online-Suchseite](https://leo-bone.github.io/HowToInvestBetter/), filtern Sie nach Stichwort, Kapitel oder Belegstufe, oder nach den drei Dimensionen „kostet es Geld / wie viel Zeit / braucht es Willenskraft“ – mehrere Bedingungen lassen sich kombinieren. Die Seite bezieht ihren Inhalt direkt aus den Dateien im `book/`-Verzeichnis; ändert sich der Text, ändert sich die Seite.
- **Hinweise verweisen aufeinander** (z. B. „siehe Kapitel 8, Hinweis 17“): Auf der Suchseite erscheint ein gestrichelter Strich; ein Klick zeigt den Titel und die „Einfach gesagt“-Version des verwiesenen Hinweises.
- **Der Reihe nach lesen**: Innerhalb jedes Kapitels sind die Hinweise nach Kosten-Nutzen absteigend sortiert; fangen Sie einfach bei den ersten paar pro Kapitel an.
- **Offline lesen oder weitergeben**: Laden Sie die [Offline-HTML (eine Datei)](https://leo-bone.github.io/HowToInvestBetter/offline.html) herunter – das ganze Buch samt Suche und Filter steckt in dieser einen Datei. Doppelklick genügt, kein Server und keine Internetverbindung nötig, auch über WeChat direkt weiterleitbar.
- **Drucken oder auf dem Handy lesen**: Laden Sie das [PDF](https://github.com/leo-bone/HowToInvestBetter/raw/main/HowToInvestBetter.pdf) herunter – A4-Layout, über 200 Seiten, mit Inhaltsverzeichnis, Seitenzahlen und Lesezeichen, jeder Abschnitt auf einer neuen Seite.
- **Auf Kindle oder anderen Lesegeräten lesen**: Laden Sie das [EPUB-E-Book](https://github.com/leo-bone/HowToInvestBetter/raw/main/HowToInvestBetter.epub) herunter; Apple Books / WeChat-Lesen / calibre / Kindle können es alle öffnen.
- **Alle drei Dateien** werden nach jeder Aktualisierung des Texts automatisch neu erzeugt; die Download-Links bleiben fest. Eine weitergegebene Kopie aktualisiert sich nicht – maßgeblich ist die Online-Version.
- **Kein Grund zur Sorge bei Kapiteltiteln mit „nicht“**: Der Titel beschreibt, was das Kapitel verhindern will; die eigentlichen Handlungen stehen in den Hinweistiteln (mit Verb am Anfang).
- **Die Zahlenkolonne nicht verstehen**: Jeder Hinweis hat eine Zeile „Einfach gesagt“, die die Forschungssprache der „Rendite“-Spalte ins Alltägliche übersetzt – diese eine Zeile genügt, um sich zu entscheiden.
- **Ehrliche Kennzeichnung**: Wo eine Schlussfolgerung Grenzen hat oder Gegenmeinungen existieren, steht `〔争议〕` (strittig); jeder Hinweis nennt seine Belegstufe (A / B / C).

## Selbst eine Kopie erzeugen

Die meisten brauchen kein Deployment: Nutzen Sie einfach die `offline.html` aus dem Repo oder öffnen Sie die [Online-Suchseite](https://leo-bone.github.io/HowToInvestBetter/).

```
git clone https://github.com/leo-bone/HowToInvestBetter.git
cd HowToInvestBetter
python3 -m http.server 8000
```

Browser öffnen: `http://localhost:8000/`. Die Suchseite ist rein statisch; `book/` und `data.js` sind ihre Daten – kein Backend, keine Datenbank, keine Abhängigkeiten zu installieren.

**Daten neu erzeugen** (nach Änderung an `book/`):

```
python3 tools/build.py
```

Dadurch werden `data.js` und die `offline.html` mit eingebetteten Daten neu erzeugt und jeder Eintrag auf Feldvollständigkeit geprüft. Das Skript nutzt nur die Python-Standardbibliothek.

**EPUB-E-Book erzeugen** (nach Änderung an `book/`, um ein gesetztes E-Book zu exportieren):

```
python3 tools/build_epub.py
```

Es wird `book/` geparst und `HowToInvestBetter.epub` erzeugt (Umschlag + Kapitel + Inhaltsverzeichnis + Stil); ebenfalls reine Standardbibliothek, keine Installation nötig.

**PDF-E-Book erzeugen** (für Druck im Buchstil):

```
pip install reportlab
python3 tools/build_pdf.py
```

Es wird `HowToInvestBetter.pdf` mit den systemeigenen CJK-Schriftarten erzeugt (Umschlag + Einführung + Inhaltsverzeichnis + Kapitel + Fußzeilenseitenzahlen). `reportlab` wird nur beim Bauen installiert; zum Öffnen des PDF braucht der Leser keine Abhängigkeiten.

**Titelbild für den Austausch erzeugen**:

```
python3 tools/gen_cover.py
```

Es wird `cover.png` (1200×630) erzeugt, für Social-Sharing-Karten und das E-Book-Cover. Benötigt `Pillow`.

**Mit einem Klick zu GitHub pushen** (wenn das lokale `git` nicht verfügbar ist):

```
python3 tools/sync.py
```

Es werden die im Repo gespeicherten Anmeldedaten genutzt, um den `main`-Branch zu committen und zu pushen.

**Inhaltsqualitätsprüfung** (vor dem Commit / für CI):

```
python3 tools/lint.py
```

Prüft: Feldvollständigkeit, keine übrig gebliebenen „zu prüfen“-Markierungen, eindeutige IDs, Belegverteilung, gültige Querverweise. Rückgabe ungleich 0 bedeutet ein Problem.

## Erläuterung der Belegstufen

- 〔A〕 Langfristige Behördenstatistik (S&P SPIVA, Börsenjahrbücher), randomisierte/langfristige Studien aus Top-Journalen, offizielle Regulierungsdokumente.
- 〔B〕 Einzelne hochwertige Studie, Backtest-Berichte renommierter Institute (Vanguard / Dalbar / Ibbotson), klassische Fachartikel.
- 〔C〕 Plausible Schlussfolgerung / breiter Konsens, logisch stichhaltig, aber ohne erzwungene exakte Quelle.

Aktuelle Verteilung: Stufe A 136, Stufe B 105, Stufe C 58.

> **Prüfstatus**: In dieser Version wurden alle Zahlen mit offiziellen Dokumenten oder renommierten Studien abgeglichen; im Text gibt es keine ungeprüften Einträge mit `〔待核实〕`. Wo eine Schlussfolgerung Grenzen hat oder Gegenmeinungen existieren, bleibt die Markierung `〔争议〕`.
