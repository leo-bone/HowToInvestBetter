# Guía de inversión de alta rentabilidad y bajo costo

> Con el mínimo de comisiones, impuestos, tiempo, esfuerzo y pérdida permanente de capital, obtener el máximo de retorno real a largo plazo, menor volatilidad, ahorro fiscal y evitar la quiebra total.

Un **manual de inversión basado en evidencia**, 24 capítulos y 302 entradas. Cada recomendación indica claramente:

- **Qué cuesta** (comisiones / impuestos / tiempo / esfuerzo / pérdida permanente de capital)
- **Qué se obtiene** (retorno anual real a largo plazo / menor volatilidad / ahorro fiscal / evitar la quiebra total)
- **Cuán sólida es la evidencia** [A estadísticas autorizadas · revistas de alto impacto · documentos oficiales ｜ B estudios individuales · informes de instituciones ｜ C inferencias razonables · normativa]
- **Fuentes originales**: solo se citan artículos académicos y documentos oficiales, nunca medios de comunicación ni cuentas de marketing.

## Cómo leer este libro

- **No hace falta hacerlo todo**: esto es una lista de opciones ordenadas por rentabilidad, no una lista de tareas. Aplicar una o dos ya cuenta; el resto puede quedar guardado y consultarse cuando se necesite.
- **Principio de los tres ceros (el criterio infalible de altísima rentabilidad)**: una acción es de "tres ceros" si su coste es cero en las tres dimensiones —dinero, tiempo y voluntad—. Hay 16 entradas que lo cumplen estrictamente (p. ej. "no invertir en productos no estándar que no comprendas", "reinvertir los dividendos", "mantener el fondo de emergencia en el mercado monetario", "aprovechar el mercado de repos", "abrir una cuenta de pensiones personal para el beneficio fiscal", "estimar el déficit de jubilación con la regla del 4%", etc.); hazlas sin pensar. Muchas más acciones están en el nivel alto de rentabilidad de "dos ceros y uno muy bajo" —en la página de búsqueda puedes filtrar por "dinero / tiempo / voluntad" para encontrar las de coste "cero".
- **Si quieres filtrar por criterios**: abre la [página de búsqueda en línea](https://leo-bone.github.io/HowToInvestBetter/) y filtra por palabra clave, capítulo o nivel de evidencia; también por las tres dimensiones "¿cuesta dinero?, ¿cuánto tiempo?, ¿requiere voluntad?", y puedes combinar varios criterios. El contenido de la página se toma directamente de los archivos de texto en `book/`; cualquier cambio en el texto se refleja en la página.
- **Las entradas se referencian entre sí** (por ejemplo, "ver cap. 8, entrada 17"): en la página de búsqueda, la referencia aparece con una línea punteada; al hacer clic se muestra allí mismo el título y la "explicación sencilla" de la entrada citada.
- **Si quieres leer en orden**: dentro de cada capítulo las entradas se ordenan de mayor a menor rentabilidad; basta con empezar por las primeras de cada capítulo.
- **Si quieres verlo sin conexión o enviárselo a alguien**: descarga la [página HTML autónoma offline](https://leo-bone.github.io/HowToInvestBetter/offline.html); todo el libro, con la búsqueda y el filtrado, está en ese único archivo: se abre con doble clic, sin servidor ni conexión, y se puede enviar directamente por WeChat.
- **Si quieres imprimirlo o leerlo en el móvil**: descarga el [PDF](https://github.com/leo-bone/HowToInvestBetter/raw/main/HowToInvestBetter.pdf), con maquetación A4, más de doscientas páginas, índice con paginación y marcadores, y cada sección en una página nueva.
- **Si quieres leerlo en Kindle u otro lector**: descarga el [libro electrónico EPUB](https://github.com/leo-bone/HowToInvestBetter/raw/main/HowToInvestBetter.epub), que abren Apple Books / WeChat Reading / calibre / Kindle.
- **Los tres formatos se regeneran automáticamente tras cada actualización del texto**; los enlaces de descarga son fijos. La copia que reenvíes no se actualizará; usa la versión en línea como referencia.
- **No te preocupes al ver títulos de capítulo que empiezan por "no"**: el título indica lo que el capítulo quiere prevenir; las acciones a realmente hacer están en los títulos de las entradas (que empiezan por un verbo).
- **Si no entiendes la fila de números**: cada entrada tiene una línea "explicación sencilla" que traduce la redacción técnica de la columna "rendimiento" a lenguaje cotidiano; con leer esa línea basta para decidir.
- **Etiquetado honesto**: cuando una conclusión tiene límites de aplicación o opiniones contrarias, se marca `〔controversia〕`; cada entrada indica su nivel de evidencia (A / B / C).

## Generar tu propia copia

La mayoría no necesita desplegarlo: basta con usar `offline.html` del repositorio o abrir la [página de búsqueda en línea](https://leo-bone.github.io/HowToInvestBetter/).

```
git clone https://github.com/leo-bone/HowToInvestBetter.git
cd HowToInvestBetter
python3 -m http.server 8000
```

Abre en el navegador `http://localhost:8000/`. La página de búsqueda es puramente estática; `book/` y `data.js` son sus datos, sin backend, sin base de datos y sin dependencias que instalar.

**Regenerar los datos** (tras modificar `book/`):

```
python3 tools/build.py
```

Regenera `data.js` y `offline.html` con datos integrados, y valida la integridad de los campos de cada entrada. El script solo depende de la biblioteca estándar de Python.

**Generar el libro EPUB** (tras modificar `book/`, si quieres exportar un libro electrónico bien maquetado):

```
python3 tools/build_epub.py
```

Analiza `book/` y genera `HowToInvestBetter.epub` (portada + capítulos + índice + estilos); también solo con la biblioteca estándar, sin dependencias.

**Generar el PDF** (para estilo de libro impreso / imprimir):

```
pip install reportlab
python3 tools/build_pdf.py
```

Genera `HowToInvestBetter.pdf` (portada + guía + índice + capítulos + numeración de página en el pie) usando las fuentes CJK integradas en el sistema. `reportlab` solo se instala al construir; para abrir el PDF el lector no necesita ninguna dependencia.

**Generar la imagen de portada para compartir**:

```
python3 tools/gen_cover.py
```

Genera `cover.png` (1200×630), para tarjetas de redes sociales y la portada del libro electrónico. Requiere `Pillow`.

**Enviar a GitHub con un clic** (cuando `git` del sistema no esté disponible):

```
python3 tools/sync.py
```

Confirma y envía (push) la rama `main` usando las credenciales ya guardadas en el repositorio.

**Validación de calidad del contenido** (antes de enviar / para CI):

```
python3 tools/lint.py
```

Comprueba: integridad de campos, ausencia de residuos de "por verificar", unicidad de ID, distribución de evidencias y validez de las referencias cruzadas. Un valor de retorno distinto de 0 indica un problema.

## Explicación de los niveles de evidencia

- 〔A〕 Estadísticas autorizadas a largo plazo (S&P SPIVA, anuarios de bolsa), estudios aleatorizados / de seguimiento en revistas de alto impacto, documentos oficiales de regulación.
- 〔B〕 Estudios individuales de alta calidad, informes de backtesting de instituciones autorizadas (Vanguard / Dalbar / Ibbotson), artículos clásicos.
- 〔C〕 Inferencias razonables / consenso amplio, lógica sólida pero sin forzar una fuente exacta.

Distribución actual: 136 entradas de nivel A, 105 de nivel B y 58 de nivel C.

> **Estado de verificación**: en esta versión todos los números se han contrastado con documentos oficiales o estudios autorizados; el texto no contiene entradas sin verificar `〔por verificar〕`; las conclusiones con límites de aplicación u opiniones contrarias siguen marcándose `〔controversia〕`.
