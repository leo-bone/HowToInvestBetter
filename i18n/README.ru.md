## Как читать

- **Не нужно делать всё сразу**: это список вариантов, отсортированных по эффективности затрат, а не перечень задач. Возьмите одну-две рекомендации — уже не зря; остальное оставьте на потом и вернётесь, когда понадобится.
- **Принцип «трёх нулей» (жёсткий критерий максимальной эффективности)**: действие считается «трёхнулевым», если **затраты = ноль, время = ноль, воля = ноль** — все три издержки равны нулю. Строго подходят 16 рекомендаций (например, «не вкладывайтесь в незнакомое и внебиржевое — по умолчанию не трогайте», «реинвестируйте дивиденды», «держите резервный фонд в фонде денежного рынка», «занимайтесь обратным РЕПО ради мелочи», «откройте индивидуальный пенсионный счёт ради налоговой льготы», «правило 4% для оценки пенсионного разрыва» и др.) — делайте их с закрытыми глазами в первую очередь. Ещё больше действий попадает в категорию высокой эффективности «два нуля и одна минимальная»: на поисковой странице можно отфильтровать по «затратам / времени / воле» отдельно на «ноль».
- **Хотите выбрать по условиям**: откройте [онлайн-страницу поиска](https://leo-bone.github.io/HowToInvestBetter/) и фильтруйте по ключевым словам, главам и уровню доказательности; также можно фильтровать по трём параметрам — «тратить деньги / тратить время / нужна ли воля» — и комбинировать их. Содержимое страницы берётся напрямую из основного текста в каталоге `book/`; измените текст — и страница обновится.
- **Рекомендации ссылаются друг на друга** (например, «см. главу 8, пункт 17»): на поисковой странице ссылка показывается пунктиром, нажмёте — и сразу увидите заголовок и «простыми словами» той рекомендации.
- **Хотите читать по порядку**: внутри каждой главы пункты отсортированы по эффективности затрат от высокой к низкой — начните с первых нескольких в каждой главе.
- **Хотите читать офлайн или отправить кому-то**: скачайте [автономный HTML в одном файле](https://leo-bone.github.io/HowToInvestBetter/offline.html) — вся книга вместе с поиском и фильтрами в одном файле; открывается двойным щелчком, без сервера и интернета, можно передать прямо в WeChat.
- **Хотите распечатать или читать на телефоне**: скачайте [PDF](https://github.com/leo-bone/HowToInvestBetter/raw/main/HowToInvestBetter.pdf) — вёрстка A4, больше двухсот страниц, с нумерацией страниц, содержанием и закладками; каждый раздел начинается с новой страницы.
- **Хотите читать на Kindle или другом ридере**: скачайте [электронную книгу EPUB](https://github.com/leo-bone/HowToInvestBetter/raw/main/HowToInvestBetter.epub) — откроется в Apple Books / WeChat Reading / calibre / Kindle.
- **Все три файла автоматически пересобираются после каждого обновления основного текста**, ссылки на скачивание неизменны; пересланная копия не обновляется — ориентируйтесь на онлайн-версию.
- **Не пугайтесь названий глав, начинающихся с «не»**: название говорит о том, чего глава хочет уберечь вас, а реальные действия — в заголовках пунктов (они начинаются с глагола).
- **Не понятны цифры**: у каждой рекомендации есть строка «простыми словами», где академический язык столбца «доходность» переведён на обыденный; достаточно прочитать только её, чтобы решить.
- **Честная маркировка**: где вывод имеет границы применимости или есть противоположное мнение, стоит `〔спорно〕`; у каждой рекомендации указан уровень доказательности (A / B / C).

## Собрать свою копию

Большинству не нужно разворачивать что-то своё: просто используйте `offline.html` из репозитория или откройте [онлайн-страницу поиска](https://leo-bone.github.io/HowToInvestBetter/).

```
git clone https://github.com/leo-bone/HowToInvestBetter.git
cd HowToInvestBetter
python3 -m http.server 8000
```

Откройте в браузере `http://localhost:8000/`. Поисковая страница полностью статична; её данные — это `book/` и `data.js`, без бэкенда, без базы данных и без зависимостей.

**Пересборка данных** (после изменения `book/`):

```
python3 tools/build.py
```

Заново сгенерирует `data.js` и `offline.html` со встроенными данными и проверит полноту полей каждой записи. Скрипт зависит только от стандартной библиотеки Python.

**Генерация электронной книги EPUB** (после изменения `book/`, если хотите экспортировать книгу с вёрсткой):

```
python3 tools/build_epub.py
```

Разберёт `book/` и сгенерирует `HowToInvestBetter.epub` (обложка + главы + содержание + стили); также только стандартная библиотека, зависимости не нужны.

**Генерация PDF-книги** (нужен стиль бумажной книги / печать):

```
pip install reportlab
python3 tools/build_pdf.py
```

Для генерации `HowToInvestBetter.pdf` (обложка + введение + содержание + главы + номера страниц внизу) используется системный CJK-шрифт. `reportlab` устанавливается только при сборке; читателю для открытия PDF никакие зависимости не нужны.

**Генерация картинки-обложки для публикаций**:

```
python3 tools/gen_cover.py
```

Сгенерирует `cover.png` (1200×630) для карточек в соцсетях и обложки книги. Требуется `Pillow`.

**Отправка в GitHub в один клик** (если на машине недоступен системный `git`):

```
python3 tools/sync.py
```

Выполнит коммит и отправит ветку `main`, используя сохранённые учётные данные репозитория.

**Проверка качества содержимого** (перед коммитом / для CI):

```
python3 tools/lint.py
```

Проверяет: полноту полей, отсутствие остатков «требует проверки», уникальность ID, распределение уровней доказательности и корректность перекрёстных ссылок. Ненулевой код возврата означает наличие проблем.

## Пояснение уровней доказательности

- 〔A〕 авторитетная многолетняя статистика (S&P SPIVA, биржевые ежегодники), рандомизированные и лонгитюдные исследования в ведущих журналах, официальные регуляторные документы.
- 〔B〕 отдельные качественные исследования, отчёты об историческом тестировании авторитетных институтов (Vanguard / Dalbar / Ibbotson), классические статьи.
- 〔C〕 обоснованные выводы / широкий консенсус: логика крепкая, но точный источник не привязывается насильно.

Текущее распределение: уровень A — 136, B — 105, C — 58.

> **Статус проверки**: все цифры в этой версии сверены с официальными документами или авторитетными исследованиями; в основном тексте нет непроверенных записей `〔требует проверки〕`; там, где вывод имеет границы применимости или есть противоположное мнение, по-прежнему стоит `〔спорно〕`.
