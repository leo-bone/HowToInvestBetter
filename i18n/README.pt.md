# Guia de Investimento de Alta Relação Custo-Benefício

> Com o mínimo de taxas, impostos, tempo, esforço e perda permanente de capital, obter o máximo de retorno real de longo prazo, menor volatilidade, economia de taxas e impostos e a prevenção de perdas totais.

[中文](../README.md) · [English](README.en.md) · [Русский](README.ru.md) · [Español](README.es.md) · **Português** · [Deutsch](README.de.md) · [Tiếng Việt](README.vi.md)

Um **manual de investimento baseado em evidências**, com 24 capítulos e 302 itens. Cada recomendação especifica:

- **O que você sacrifica** (taxas / impostos / tempo / esforço / perda permanente de capital)
- **O que você ganha** (retorno real anualizado de longo prazo / menor volatilidade / economia de taxas e impostos / prevenção de perdas totais)
- **Quão sólida é a evidência**〔A estatísticas autorizadas · periódicos de ponta · documentos oficiais ｜ B estudos individuais · relatórios institucionais ｜ C inferências razoáveis · regulamentos〕
- **Fontes originais**: citamos apenas artigos acadêmicos e documentos oficiais, nunca mídia independente ou contas de marketing.

## Como ler

- **Não precisa fazer tudo**: este é um cardápio organizado por custo-benefício, não uma lista de tarefas. Leve um ou dois itens e já vale; o resto fica guardado para quando precisar consultar de novo.
- **Princípio dos três zeros (o padrão de altíssimo custo-benefício)**: uma ação é "três zeros" quando **custo = zero, tempo = zero, disciplina = zero**, os três custos em zero. Há 16 itens que atendem estritamente a isso (como "não investir em ativos não padronizados que você não conhece, por padrão não toque", "reinvestir dividendos", "deixar o fundo de reserva no mercado monetário", "cazar migalhas com repo reverso", "abrir conta individual de previdência para usufruir do benefício fiscal", "usar a regra de 4% para estimar a lacuna da aposentadoria", etc.); faça esses de cara, sem pensar. Há ainda mais ações na faixa de alto custo-benefício "dois zeros e um custo muito baixo" — na página de busca dá para filtrar "zero" em "custo / tempo / disciplina" separadamente para descobrir.
- **Quer filtrar por critérios**: abra a [página de busca online](https://leo-bone.github.io/HowToInvestBetter/), filtre por palavra-chave, capítulo ou nível de evidência; também dá para filtrar pelas três dimensões "gasta dinheiro? / quanto tempo? / exige disciplina?", e combinar vários critérios. O conteúdo da página vem direto dos arquivos em `book/`, e se o texto muda, a página muda junto.
- **Os itens se referenciam entre si** (do tipo "veja o item 17 do capítulo 8"): na página de busca, a referência aparece com uma linha tracejada; clique e o título e a "versão simples" do item citado aparecem ali mesmo.
- **Quer ler em ordem**: dentro de cada capítulo os itens estão do maior para o menor custo-benefício; comece pelos primeiros itens de cada capítulo.
- **Quer ler offline ou mandar para outra pessoa**: baixe o [HTML offline de arquivo único](https://leo-bone.github.io/HowToInvestBetter/offline.html); o livro inteiro, com busca e filtros, está nesse único arquivo. Abre com duplo clique, sem servidor e sem internet; dá para enviar direto no WeChat.
- **Quer imprimir ou ler no celular**: baixe o [PDF](https://github.com/leo-bone/HowToInvestBetter/raw/main/HowToInvestBetter.pdf), em formato A4, com mais de duzentas páginas, sumário com páginas e marcadores, e cada seção começa em página nova.
- **Quer ler no Kindle ou outro leitor**: baixe o [e-book EPUB](https://github.com/leo-bone/HowToInvestBetter/raw/main/HowToInvestBetter.epub), abre no Apple Books / WeChat Reading / calibre / Kindle.
- **Os três formatos são gerados automaticamente a cada atualização do texto**, e os links de download não mudam; a cópia que você repassou não acompanha as atualizações, use sempre a versão online como referência.
- **Não se assuste com títulos de capítulo que começam por "Não"**: o título diz o que o capítulo quer evitar; a ação de fato está no título do item (verbo no início).
- **Não entendeu aquele número**: cada item tem uma linha "versão simples" que traduz a linguagem de pesquisa da coluna "retorno" para o português do dia a dia; basta ler essa linha para decidir.
- **Marcação honesta**: quando uma conclusão tem limites de aplicação ou posição oposta, marcamos `〔controvers
o〕`; cada item indica seu nível de evidência (A / B / C).

## Compile Seu Próprio Exemplar

A maioria não precisa implantar nada: use direto o `offline.html` do repositório ou abra a [página de busca online](https://leo-bone.github.io/HowToInvestBetter/).

```
git clone https://github.com/leo-bone/HowToInvestBetter.git
cd HowToInvestBetter
python3 -m http.server 8000
```

Abra no navegador `http://localhost:8000/`. A página de busca é puramente estática; `book/` e `data.js` são seus dados, não há back-end, não há banco de dados e não precisa instalar dependências.

**Gerar os dados de novo** (após alterar `book/`):

```
python3 tools/build.py
```

Isso regera `data.js` e o `offline.html` com dados embutidos, e faz a verificação de integridade dos campos de cada item. O script depende apenas da biblioteca padrão do Python.

**Gerar o e-book EPUB** (após alterar `book/`, para exportar um e-book bem formatado):

```
python3 tools/build_epub.py
```

Analisa `book/` e gera `HowToInvestBetter.epub` (capa + capítulos + sumário + estilo); também usa só a biblioteca padrão, sem instalar dependências.

**Gerar o e-book PDF** (para um estilo de livro impresso / impressão):

```
pip install reportlab
python3 tools/build_pdf.py
```

Usa a fonte CJK embutida no sistema para gerar `HowToInvestBetter.pdf` (capa + introdução + sumário + capítulos + número de página no rodapé). O `reportlab` é instalado só na geração; para abrir o PDF o leitor não precisa de nenhuma dependência.

**Gerar imagem de capa para compartilhar**:

```
python3 tools/gen_cover.py
```

Gera `cover.png` (1200×630), usado em cartões de compartilhamento social e na capa do e-book. Precisa de `Pillow`.

**Enviar para o GitHub com um comando** (quando o `git` do sistema local não estiver disponível):

```
python3 tools/sync.py
```

Usa as credenciais já salvas no repositório para commitar e enviar o branch `main`.

**Verificação de qualidade do conteúdo** (antes de commitar / para CI):

```
python3 tools/lint.py
```

Verifica: integridade dos campos, nenhum resíduo de "a verificar", IDs únicos, distribuição das evidências e validade das referências cruzadas. Retorna não-zero se houver problema.

## Explicação da Classificação de Evidências

- 〔A〕Estatísticas autorizadas de longo prazo (S&P SPIVA, anuários de bolsas), estudos randomizados / de acompanhamento em periódicos de ponta, documentos oficiais de reguladores.
- 〔B〕Estudos individuais de alta qualidade, relatórios de backtest de instituições autorizadas (Vanguard / Dalbar / Ibbotson), artigos clássicos.
- 〔C〕Inferências razoáveis / consenso amplo, lógica sólida mas sem forçar uma fonte exata.

Distribuição atual: 136 itens de nível A, 105 de nível B e 58 de nível C.

> **Status de verificação**: nesta versão todos os números foram conferidos com documentos oficiais ou pesquisas autorizadas; o texto não tem itens `〔a verificar〕` não checados; quando uma conclusão tem limites de aplicação ou posição oposta, ainda assim marcamos `〔controvers
o〕`.
