# 高性价比投资指南

> 用最少的费用、税收、时间、精力与本金永久损失，换回最多的长期真实回报、更低波动、税费节省与避开归零。

## 怎么读

- **不用全做**：这是一份按性价比排好的备选单，不是任务清单。挑走一两条就算数，剩下的放着，需要时再回来查。
- **三零原则（极高性价比死标准）**：一条动作若**花费＝无、时间＝无、毅力＝无**，三项成本全为零，就是「三零」。严格符合的共 16 条（如「不熟不投非标默认不碰」「分红再投」「货币基金放应急金」「逆回购捡芝麻」「开个人养老金账户吃税优」「4% 法则估养老缺口」等），闭眼先做。更多动作是「两项为零、一项极低」的高性价比档——检索页可按「花费／时间／毅力」分别筛「无」来挖掘。
- **想按条件挑**：打开[在线检索页](https://leo-bone.github.io/HowToInvestBetter/)，按关键词、章节、证据等级来筛，也可以按「花不花钱、花多少时间、要不要毅力」这三样筛，几个条件能叠着用。页面内容直接取自 `book/` 目录里的正文，正文一改，页面跟着改。
- **条目之间会互相指路**（「见第 8 章第 17 条」这种）：在检索页里，指路带一条虚线，点一下就地显示被指的那条的标题和「说人话」。
- **想按顺序读**：每章内条目按性价比从高到低排列，从每章前几条开始看就行。
- **想离线看、想发给别人**：下载[离线单文件 HTML](https://leo-bone.github.io/HowToInvestBetter/offline.html)，整本书连同检索和筛选都在这一个文件里，双击就开，不用服务器也不用联网，微信里也能直接传。
- **想打印或在手机上看**：下载 [PDF](https://github.com/leo-bone/HowToInvestBetter/raw/main/HowToInvestBetter.pdf)，A4 排版、两百多页，带目录页码和书签，每节另起一页。
- **想在 Kindle 或其他阅读器上读**：下载 [EPUB 电子书](https://github.com/leo-bone/HowToInvestBetter/raw/main/HowToInvestBetter.epub)，Apple Books／微信读书／calibre／Kindle 都能打开。
- **三样都是正文每次更新后自动重新生成的**，下载链接固定不变；转发出去的那一份不会跟着更新，以在线版为准。
- **看到「不要」开头的章标题不用紧张**：章标题说的是这一章想防住的事，真正要做的动作写在条目标题里（动词开头）。
- **看不懂那串数字**：每条都有一行「说人话」，把「收益」栏的研究写法翻成日常说法，只看这一行就够拿主意。
- **诚实标注**：凡结论存在适用边界或相反观点的，标 `〔争议〕`；每条都注明证据等级（A／B／C）。

## 自己跑一份

多数人用不着部署：直接用仓库里的 `offline.html`，或开[在线检索页](https://leo-bone.github.io/HowToInvestBetter/)即可。

```
git clone https://github.com/leo-bone/HowToInvestBetter.git
cd HowToInvestBetter
python3 -m http.server 8000
```

浏览器开 `http://localhost:8000/`。检索页是纯静态的，`book/` 与 `data.js` 就是它的数据，没有后端、没有数据库、不用装依赖。

**重新生成数据**（改了 `book/` 后）：

```
python3 tools/build.py
```

会重新生成 `data.js` 与内联数据的 `offline.html`，并对每条做字段完整性校验。脚本仅依赖 Python 标准库。

**生成 EPUB 电子书**（改了 `book/` 后，想导出排版好的电子书）：

```
python3 tools/build_epub.py
```

会解析 `book/` 生成 `HowToInvestBetter.epub`（封面 + 分章 + 目录 + 样式），同样是纯标准库、无需安装依赖。

**生成 PDF 电子书**（想要纸质书风格 / 打印）：

```
pip install reportlab
python3 tools/build_pdf.py
```

会用系统内置 CJK 字体生成 `HowToInvestBetter.pdf`（封面 + 导读 + 目录 + 分章 + 页脚页码）。`reportlab` 仅构建时安装，读者打开 PDF 无需任何依赖。

**生成分享封面图**：

```
python3 tools/gen_cover.py
```

会生成 `cover.png`（1200×630），用于社交分享卡片与电子书封面。需 `Pillow`。

**一键推送到 GitHub**（本机系统 `git` 不可用时）：

```
python3 tools/sync.py
```

会用仓库已存的凭据提交并推送 `main` 分支。

**内容质量校验**（提交前 / CI 用）：

```
python3 tools/lint.py
```

检查：字段完整性、无「待核实」残留、ID 唯一、证据分布、交叉引用有效。返回非 0 表示有问题。

## 证据分级说明

- 〔A〕权威长期统计（标普 SPIVA、交易所年鉴）、顶刊随机／追踪研究、官方监管文件。
- 〔B〕单项高质量研究、权威机构（Vanguard／Dalbar／Ibbotson）回测报告、经典论文。
- 〔C〕合理推论／广泛共识，逻辑硬但不勉强挂精确出处。

当前分布：A 级 136 条、B 级 105 条、C 级 58 条。

> **核实状态**：本版所有数字均已核对官方文件或权威研究，正文无 `〔待核实〕` 未核实条目；凡结论存在适用边界或相反观点的，仍标 `〔争议〕`。
